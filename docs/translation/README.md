# 채팅 자동 번역 설정

`완성형 출력` 모드에서 설정 버튼을 누르면 채팅 자동 번역을 설정할 수 있습니다.
사용할 서비스에 맞는 문서를 참고하세요.

- [Microsoft Translator](microsoft-translator.md)
- [Google Cloud Translation](google-cloud-translation.md)
- [LibreTranslate](libretranslate.md)

번역 결과는 원문 뒤에 `[번역] : 내용` 형식으로 표시됩니다. 길드, 그룹, 귓속말,
일반 대화, LFG 중 원하는 채널만 선택할 수 있습니다.

API 키는 다른 사람에게 전달하거나 GitHub, 게시판, 로그에 올리지 마세요. 앱에 저장한
API 키는 현재 Windows 사용자 계정으로 암호화됩니다.
