# KDAOC composition font

`DaocHangulKdaoc.ttf` is the original component-composition font used by
`kdaoc.exe` as its `DAOCHFONT6_TEST8.TTF` resource.

- Installed source name: `ui\fonts\myriadpro-regular-han.ttf`
- File size: 226,832 bytes
- SHA-256: `4CB6B89D346DC62DE3125B8A89059350C322717D710565471514EEFAD2FA2515`
- Unicode Hangul syllable glyphs: none
- Input contract: KDAOC component code points

The active encoder only emits component code points present in this font.
U+0020 remains an empty space glyph with its original advance width.

## Extended composition font

`DaocHangulExtended.ttf` is generated from the KDAOC font and D2CodingLigature
Bold by `tools\build_d2_extended_legacy_font.py`. Bold is used because its
component strokes survive the game's 11 px chat rasterization more clearly.

- No-final choseong glyphs: 19 separate Windows-1252-printable Unicode IDs
- Hangul component outlines: D2CodingLigature compatibility jamo
- Component positions and advances: original KDAOC metrics
- No-final choseong: original KDAOC outline and horizontal geometry, vertically stretched to `y=366..833`
- D2Coding source: `third_party\D2CodingLigature\D2CodingBold-Ver1.3.2-20180524-ligature.ttf`
- D2Coding source SHA-256: `2D7D153B6BC29A7216E62070348E1240305C95263A78DA2B5EF836CF5CE59343`
- Raw C1 controls U+0080..U+009F: never emitted by the encoder
- DAoC raw byte aliases: mapped font-side to the same 19 extended outlines
- Unicode and 8-bit Macintosh/ANSI cmap tables both contain the raw aliases
- U+0020: always a unique empty space glyph
- U+00A0: no-final medial glyph, never aliased to U+0020

## Precomposed render font

`DaocHangulPrecomposed.ttf` is generated by
`tools\build_precomposed_font.py`. It keeps every KDAOC Latin, punctuation,
component and Space glyph and adds all 11,172 D2Coding Bold Hangul
syllables. Hangul advances are reduced to 823 font units to match the compact
width of a KDAOC no-final composition. U+0020 keeps the KDAOC 212-unit advance
and empty outline.

`DaocLegacyFonts.br` stores the KDAOC, extended and precomposed fonts in one
Brotli stream to exploit their shared table and outline data. Rebuild all files with:

```powershell
.\tools\build_legacy_font_bundle.ps1
```
